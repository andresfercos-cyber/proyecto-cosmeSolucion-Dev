# Habit Tracker Dashboard

Aplicacion web para registrar habitos diarios, marcarlos como completados y revisar el progreso de los ultimos 7 dias.

## Funcionalidades

- Crear y eliminar habitos.
- Marcar habitos como completados por dia.
- Filtros: todos, completados y pendientes.
- Porcentaje de progreso semanal.
- Grafica simple de los ultimos 7 dias.
- Racha actual de dias completos.
- Modo oscuro.
- Persistencia con `localStorage`.
- Diseno responsive para movil y escritorio.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

Abre `index.html` directamente en tu navegador.

Tambien puedes publicarlo con GitHub Pages:

1. Sube este proyecto a un repositorio de GitHub.
2. Ve a `Settings > Pages`.
3. Selecciona la rama principal y la carpeta raiz.
4. Guarda los cambios.

## Idea para practicar mas

Puedes agregar categorias, recordatorios, editar nombres de habitos o exportar el progreso semanal.
